FuguLib

FuguLib covers the parts of writing an OpenBSD-style daemon in Perl that the base system leaves to you: going into the background, writing a PID file, dropping privileges, reaping children, handling signals, logging to syslog or stderr depending on how the program was started, restricting itself with pledge and unveil, and advertising over mDNS without shelling out.

Nine modules, using only core Perl. OpenHAP is built on it; nothing in it knows about OpenHAP.

The modules

FuguLib::Daemon
Fork, setsid, redirect the standard descriptors. A callback runs in the parent before it exits, which is where the PID file gets written.
FuguLib::Privdrop
Drop from root to a named user and group, then verify that root cannot be regained.
FuguLib::Process
Spawn, exec, verify a child actually survived start-up, terminate with a grace period before SIGKILL, reap zombies, and wait for exit.
FuguLib::Signal
Register handlers for graceful shutdown or for a flag a long-running loop can poll, with a stack of cleanup callbacks and restoration of the previous handlers.
FuguLib::Log
One interface over syslog, stderr and silence, with level filtering and printf-style formatting, so a daemon and a CLI tool can share code.
FuguLib::State
PID file reading and writing with locking, plus stale-PID detection built on FuguLib::Process.
FuguLib::Sandbox
pledge(2) and unveil(2) as a platform abstraction: real on OpenBSD, a no-op everywhere else, so callers never test the operating system themselves. Failures die; there is no warn-and-continue mode.
FuguLib::Imsg
The base-system imsg framing — a fixed native-endian header and a payload — over any connected stream socket, with whole-message reads across short counts.
FuguLib::MDNS
Publish services through mdnsd(8) by speaking its control protocol directly, no mdnsctl child process; the held socket is the advertisement's lifetime.

Reference

Each module has a section 3p manual page, installed with OpenHAP — so man FuguLib::Daemon works on a machine that has it — and listed under FuguLib in the manuals.

Name

Fugu is the pufferfish, after OpenBSD’s mascot.
