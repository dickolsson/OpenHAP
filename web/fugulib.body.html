FuguLib

FuguLib does the tasks that the base system leaves to an OpenBSD-style daemon in Perl. A daemon must go into the background, write a PID file, drop privileges, reap children, and answer signals. It must log to syslog or to stderr, as applicable to how it started. It must limit itself with pledge and unveil, and advertise over mDNS without a child process. FuguLib supplies these functions.

FuguLib has nine modules and uses only core Perl. OpenHAP uses FuguLib; FuguLib does not know about OpenHAP.

The modules

FuguLib::Daemon
The module forks, calls setsid, and redirects the standard descriptors. A callback runs in the parent before the parent exits; the callback writes the PID file.
FuguLib::Privdrop
The module drops from root to a specified user and group. It then makes sure that the process cannot get root again.
FuguLib::Process
The module spawns and execs children, and makes sure that a child is alive after startup. It stops a child with a grace period before SIGKILL, reaps zombies, and waits for exit.
FuguLib::Signal
The module registers handlers for a controlled shutdown, or for a flag that a long loop can poll. It keeps a stack of cleanup callbacks and puts the previous handlers back.
FuguLib::Log
The module gives one interface for syslog, stderr, and silence, with level filters and printf-style formats. Thus a daemon and a CLI tool can use the same code.
FuguLib::State
The module reads and writes PID files with locks, and finds stale PIDs with FuguLib::Process.
FuguLib::Sandbox
The module is a platform abstraction for pledge(2) and unveil(2): the calls are real on OpenBSD and do nothing on other platforms. Thus the callers do not examine the operating system. A method that fails dies; there is no warn-and-continue mode.
FuguLib::Imsg
The module supplies the base-system imsg framing — a fixed native-endian header and a payload — over a connected stream socket. It reads full messages when the socket returns short counts.
FuguLib::MDNS
The module publishes services through mdnsd(8) with its control protocol directly, not through a mdnsctl child process. The advertisement stays active while the module holds the socket.

Reference

Each module has a section 3p manual page under its full name — thus man FuguLib::Daemon finds the page. The pages are also listed under FuguLib in the manuals.

Name

Fugu is the pufferfish, the mascot of OpenBSD.
