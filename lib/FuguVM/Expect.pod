=head1 NAME

FuguVM::Expect - drive the OpenBSD installer over the serial console

=head1 SYNOPSIS

    use FuguVM::Expect;

    my $expect = FuguVM::Expect->new(
        host => '127.0.0.1',
        port => $console_port,
    );

    $expect->run_install({
        root_password => $password,
        proxy_url     => $proxy->guest_url,
    }) or die "installation failed\n";

=head1 DESCRIPTION

The OpenBSD installer asks questions that no protocol answers, so an
L<expect(1)> script types them. The scripts ship under
F<share/fuguvm/expect>, and L<FuguLib::File> resolves them against the
install root.

The run is a passthrough: the child writes straight to the terminal of
the caller. An installation writes for tens of minutes, and an
operator who waits needs to see the progress while it happens.

=head1 METHODS

=head2 new

    FuguVM::Expect->new(host => ..., port => ..., timeout => ...)

The host and port name the serial console. The default timeout is 180
seconds, or C<FUGUVM_TIMEOUT> when the environment sets it. The
timeout travels to the script in that variable.

=head2 script_path

    FuguVM::Expect->script_path($name)

Return the path of a shipped script, or C<undef>. The method also
works on the class: L<FuguVM::ImageCache> hashes the installer script
into its cache key, so it must resolve the script the same way
C<run_install> does.

=head2 run_install

    $expect->run_install(\%config)

Drive a complete installation. The configuration gives the root
password and the proxy URL that the guest fetches its sets through.

=head2 run_script

    $expect->run_script($script, @args)

Run one script against this console. The argument is a path, or the
name of a shipped script.
