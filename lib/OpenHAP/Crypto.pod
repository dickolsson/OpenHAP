=head1 NAME

OpenHAP::Crypto - crypto primitives for HAP, wrappers over CPAN modules

=head1 SYNOPSIS

    use OpenHAP::Crypto;

    # Generate Ed25519 keypair
    my ($secret, $public) = OpenHAP::Crypto::generate_keypair_ed25519();

    # Sign and verify
    my $sig = OpenHAP::Crypto::sign_ed25519($message, $secret, $public);
    my $valid = OpenHAP::Crypto::verify_ed25519($sig, $message, $public);

    # X25519 key exchange
    my ($our_secret, $our_public) = OpenHAP::Crypto::generate_keypair_x25519();
    my $shared = OpenHAP::Crypto::derive_shared_secret($our_secret, $their_public);

    # ChaCha20-Poly1305 encryption
    my ($ct, $tag) = OpenHAP::Crypto::chacha20_poly1305_encrypt($key, $nonce, $pt, $aad);
    my $pt = OpenHAP::Crypto::chacha20_poly1305_decrypt($key, $nonce, $ct, $tag, $aad);

=head1 DESCRIPTION

This module holds thin wrappers over the CPAN modules that do the
work. The wrappers give the callers one argument order. They also
give one place that shows which module supplies each function. These
are the modules:

=over 4

=item * Ed25519 signatures - L<Crypt::Ed25519>

=item * X25519 key exchange - L<Crypt::Curve25519>

=item * ChaCha20-Poly1305 - L<Crypt::AuthEnc::ChaCha20Poly1305>

=item * HKDF-SHA-512 - L<Crypt::KeyDerivation>

=back

The module also holds the SRP-6a group parameters for L<OpenHAP::SRP>.
These parameters come from F<spec/HAP-Pairing.md> (the RFC 5054
3072-bit group, C<g> = 5). The module reads random bytes from
F</dev/urandom>.

=cut
