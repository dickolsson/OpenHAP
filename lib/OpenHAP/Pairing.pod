=head1 NAME

OpenHAP::Pairing - HAP pairing protocol implementation

=head1 SYNOPSIS

    use OpenHAP::Pairing;

    my $pairing = OpenHAP::Pairing->new(
        pin => '9876-5432',
        storage => $storage,
        accessory_ltsk => $ltsk,
        accessory_ltpk => $ltpk,
    );

    my $response = $pairing->handle_pair_setup($body, $session);
    my $response = $pairing->handle_pair_verify($body, $session);

=head1 DESCRIPTION

This module implements the HAP pairing protocol. The protocol has the
pair-setup (SRP) flow and the pair-verify (X25519) flow.

L<Protocol::HAP::SRP>, L<Protocol::HAP::Crypto>, F<spec/HAP-Pairing.md>

=cut
