=head1 NAME

OpenHAP::Accessory - base class for HAP accessories

=head1 SYNOPSIS

    use OpenHAP::Accessory;

    my $accessory = OpenHAP::Accessory->new(
        aid => 1,
        name => 'My Accessory',
        manufacturer => 'Acme Corp',
        model => 'Model X',
    );

    $accessory->add_service($service);

=head1 DESCRIPTION

This module supplies the base class for HomeKit accessories. Each
accessory holds the necessary Accessory Information service.

=head1 SEE ALSO

L<OpenHAP::Service>, F<spec/HAP.md>

=cut
